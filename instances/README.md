# Instancias del caso

La carpeta `standard/` contiene doce instancias YAML **sintéticas**: 15, 20,
25 y 30 cirugías, con tres réplicas por tamaño. Se copiaron sin modificar de
la copia local del catálogo docente usado en los pilotos previos.

La procedencia general del caso es el repositorio
[OII464_Hospitales](https://github.com/Saicooh/OII464_Hospitales) del profesor.
El `manifest.json` de cada experimento documenta SHA-256 de los doce archivos
y el digest canónico interno de cada instancia. Esas identidades permiten
verificar que las tres políticas usaron exactamente los mismos datos.

Estas instancias no deben describirse como pacientes reales ni confundirse con
los cuatro JSON que la presentación del taller menciona como ejemplos.
